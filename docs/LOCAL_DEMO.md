# 本地演示用例

本文件记录 M14 新增的本地 fake data 和可复制测试问题。所有订单、用户、物流和规则均为人工构造，只用于本地演示和自动化测试。

## 启动方式

后端：

```bash
/opt/anaconda3/envs/rag_910/bin/python -m uvicorn api.main:app --host 127.0.0.1 --port 8001 --reload
```

前端：

```bash
cd frontend
npm run dev
```

打开：

```text
http://127.0.0.1:5173/workspace
```

## 页面验收

- `/workspace`：逐条输入上面的推荐问题，观察回复草稿、RAG 来源、审核状态和实时 Agent Step。
- `/tickets`：查看自动创建或复用的物流工单、审核工单和优先级。
- `/runs`：查看每次请求的 Agent Trace 和 Trace Waterfall。
- `/dashboard`：观察工单数量、Agent 成功率、风险榜和统计图变化。

## 本地飞书审核模拟

真实飞书卡片按钮暂时后置。本地阶段使用 callback 接口模拟审核动作：

```bash
curl -s -X POST http://127.0.0.1:8001/api/feishu/callback \
  -H 'Content-Type: application/json' \
  -d '{"event_id":"FEISHU-LOCAL-APPROVAL-001","ticket_id":"替换成待审核工单ID","action":"approve","operator":"主管A"}'
```

可选动作：

```text
approve
reject
manual_confirm
```
